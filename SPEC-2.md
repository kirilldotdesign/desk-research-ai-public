# SPEC 2 — афиша по моему вкусу

Статус: **v3** (04.11.2026), вопросы закрыты. Ждёт ручную разметку «до» и «утверждаю». Код не писать до «утверждаю» внизу.
Предыдущая: `SPEC.md` (SPEC 1, клубная афиша, сделано 04.11).

## Для кого и зачем
Для Kirill. Лента показывает всю афишу, а уведомления — только то, что совпадает с его вкусом.
Вкус задан папкой `~/Music/DADA DANCE` (2642 трека, теги жанров) и его любовью к экстремальной музыке.

## Идеальный сценарий (цель всех следующих спек)
Бот обходит все клубы Гамбурга, у каждого события есть жанр, бот присылает только концерты и вечеринки
любимых жанров и артистов. Список вкусов хранится в одном месте и пополняется. Потом добавляются похожие
артисты: «нравится A → покажу B».

Разбивка по спекам:
- **SPEC 2 (эта):** список вкусов, жанр у каждого события, уведомления только по вкусу.
- **SPEC 3:** все клубы через агрегаторы (ohschonhell, Clubkombinat) + Hafenklang обратно.
- **SPEC 4:** артисты в событиях + похожие артисты (Last.fm).

## Решения (ответы Kirill, 04.11)
1. Личные метки из папки **не жанры**: OWN, RVB, DGV, Charts, Cover, Weird — исключить. CEE — регион
   (Восточная Европа).
2. Экстрим в списке вкусов: grindcore, goregrind, noisegrind / noisecore, powerviolence, crust punk,
   d-beat, death metal, black metal, sludge, mathcore, harsh noise, harsh noise wall, power electronics,
   japanoise, death industrial. **Industrial — нет.**
3. Список вкусов — **файл `taste.yaml` в репо** (правка в iA Writer → коммит → деплой).
   Команды бота (`/like`, `/unlike`) — позже.
4. **Два сигнала:** событие по вкусу появилось в афише → сразу короткое сообщение «Новое по твоему вкусу»;
   в день события оно ещё раз в утренней сводке.
5. **Совпадение = стиль из списка, или регион из списка, или артист из папки DADA DANCE.**
   Регион важен сам по себе: Kirill любит региональную и традиционную музыку (Balkan Night, Arabic Disco,
   Afro…). Традиционная / фолк / world — отдельный стиль в списке.
6. **Стоп-список стилей** в `taste.yaml`: стиль из него не даёт совпадения, даже если регион свой
   (пример: «Latin Rave» с реггетоном). Состав — открытый вопрос 4.

## Что меняем и где
- `taste.yaml` (новый): стили + артисты; скрипт, который собирает стартовый список из папки (локально,
  в репо попадает только результат).
- `worker/`: промпт v3 — жанр из фиксированного списка (1–3 метки) вместо свободной фразы-тега; фраза
  «что это» остаётся.
- `worker/`: у события ещё и регион / происхождение музыки (если понятен).
- `bot/`: сопоставление события со вкусом (стиль, регион, артист, стоп-список); мгновенное сообщение о новом совпадении; утренняя сводка только
  по совпадениям (+ «ещё N событий в ленте»; без совпадений — одна строка).
- `tests/`: сопоставление, фильтр сводки, разбор жанров.
