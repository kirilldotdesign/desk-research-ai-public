# hamburg-clubnacht

Форк `vasilievyakov/desk-research-ai-public` (курс AI Builders Lab). Сейчас это шаблон «разговоры об AI»,
цель — дайджест клубных событий Гамбурга в Telegram. Деплой: Coolify курса, проект «Kirill Clubnacht»,
Git Source = этот форк, ветка `master`. Схема блоков и запуск — в `README.md`.

## Правила работы

1. **Код только после «утверждаю».** Любое изменение начинается с `SPEC.md`: для кого и зачем, KPI
   (порог / сейчас), что меняем и где, задачи по порядку, открытые вопросы. Пока Kirill не написал
   «утверждаю» под спекой, код не трогать.
2. **KPI меряется до и после.** Перед первой задачей замер «до» по реальной базе, после каждой задачи
   замер «после». Цифры записать в `SPEC.md`. Стало хуже, чем «до» → откатить задачу и сказать.
3. **Только то, что в спеке.** Соседние файлы не «улучшать», репо не перестраивать. Заметил проблему
   вне задачи → записать в раздел «Бэклог» спеки и сказать, не чинить молча.
4. **Одна задача = один коммит.** В сообщении коммита номер задачи из спеки (`T1: …`).
5. **Тест на каждую задачу.** Тесты в `tests/`, стандартный `unittest`, без сети и без живой базы.
   Перед коммитом прогнать все: `python -m unittest discover tests`. Красные тесты → не коммитить.
6. **Отклонения от спеки — до коммита.** Пришлось сделать иначе, чем написано → сначала сказать Kirill,
   потом коммит.
7. **Никаких ключей в репо.** `OPENROUTER_API_KEY`, `TELEGRAM_TOKEN`, `DATABASE_URL` живут только
   в переменных Coolify / локальном `.env` (он в `.gitignore`). Ключи не печатать в чат и в логи.

## Деплой

`git push` в `master` → в Coolify Redeploy → Scheduled Tasks → `collector` → Execute Now.
Push делается только по просьбе Kirill.
